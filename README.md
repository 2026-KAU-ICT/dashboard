# A-Hook

**A-Hook**은 건설 현장의 고소 작업 중 발생할 수 있는 안전고리 미체결과 추락 사고를 예방하기 위한 **스마트 안전 관제 시스템**입니다.

작업자 조끼에 부착된 ESP32 기반 장치가 안전고리 체결 여부와 추락 징후를 현장에서 판단하고, 작업 구역별 게이트웨이가 데이터를 수집해 현장 관리자용 웹 대시보드에 통합 표시합니다.

---

## 문제 정의

건설 현장의 추락 사고는 대부분 짧은 순간의 미체결, 작업자 위치 파악 실패, 사고 감지 지연에서 시작됩니다. 특히 고층 구조물과 철근, 콘크리트가 많은 현장은 통신 환경이 불안정하고, 현장 관리자가 모든 작업자의 안전고리 체결 상태를 실시간으로 확인하기 어렵습니다.

A-Hook은 이러한 문제를 해결하기 위해 작업자 단말, 구역별 게이트웨이, 통합 관제 대시보드를 하나의 흐름으로 연결합니다.

---

## 서비스 목표

* 작업자 안전고리 체결 여부를 실시간으로 확인
* 미체결 상태로 위험 구역에 진입한 작업자를 즉시 식별
* 추락 징후 발생 시 0.2초 이내 수준의 빠른 시각 알림 제공
* 현장 관리자에게 전체 작업자 상태, 위치, 배터리, 에어백 상태를 한 화면에서 제공
* 사고 이후 로그 데이터를 축적하여 사후 분석과 안전 교육 자료로 활용

---

## 시스템 동작 흐름

1. 작업자가 A-Hook 조끼를 착용합니다.
2. 조끼 내부의 ESP32가 센서값을 읽고 안전고리 체결 여부와 추락 위험 여부를 판단합니다.
3. 조끼는 Bluetooth/BLE로 가까운 작업 구역 게이트웨이에 상태 데이터를 전송합니다.
4. 게이트웨이는 여러 조끼의 데이터를 모아 WebSocket으로 대시보드에 중계합니다.
5. 웹 대시보드는 선택한 층의 작업자 상태를 층별 관제뷰 위에 실시간으로 표시합니다.
6. 관리자는 웹에서 특정 작업자의 조끼 사이렌, LED, 층별·전체 대피 알림을 게이트웨이를 통해 원격 제어합니다.

현장 세팅 단계에서는 관리자가 위성 지도 또는 항공뷰 위에 각 층의 게이트웨이 기준점을 먼저 배치합니다. A-Hook은 이 기준점들을 연결한 게이트웨이 존을 기준으로 작업자 상대 좌표를 해석하기 때문에, 실제 비콘 설치 위치와 관제 화면의 좌표계를 맞출 수 있습니다.

중요한 점은 **웹 브라우저가 조끼와 Bluetooth로 직접 연결하지 않는 구조**라는 것입니다. 일반 브라우저는 Bluetooth 지원이 제한적이고 iPhone 환경에서는 제약이 크기 때문에, A-Hook은 게이트웨이가 BLE 데이터를 수집하고 웹은 WebSocket 기반으로 통합 데이터를 확인하는 방식으로 설계했습니다.

따라서 조끼의 ESP32는 센싱과 엣지 판단, BLE 전송에 집중하고, 작업 구역별 게이트웨이가 여러 조끼의 데이터를 모아 WebSocket으로 대시보드에 중계합니다. 시연 단계에서는 ESP32 기반 게이트웨이가 웹소켓 서버 역할을 함께 수행해 별도 서버 부담과 지연 시간을 줄이는 구조를 목표로 합니다.

## 핵심 기능

### 실시간 현장 모니터링

항공뷰 기반 현장 지도 위에 1층, 2층, 3층, 4층 화면을 각각 독립된 층별 관제뷰로 표시합니다. 작업자의 상대 좌표는 실제 지도 픽셀과 현장 거리 단위로 변환되어 표시되며, 관리자는 층을 전환해 해당 층 작업자만 빠르게 확인할 수 있습니다.

작업자 상태는 정상, 경고, 비상으로 구분됩니다. 정상 작업자는 초록색, 미체결 상태나 위험 구역 진입 작업자는 노란색, 추락 징후가 감지된 작업자는 빨간색으로 강조되어 현장에서 즉시 알아볼 수 있습니다.

### 위험 구역 관리

현장 관리자는 A-Hook 존을 지도 위에서 조정할 수 있습니다. 각 층별 위험 구역의 중심, 반경, RSSI 임계값은 평소 잠금 상태로 유지되며, 관리자가 변경 모드로 전환한 뒤 수정하고 적용하면 게이트웨이를 통해 현장 장치 설정에 반영되는 구조입니다.

이를 통해 현장 구조가 바뀌거나 작업 구역이 변경되어도 관리자가 직접 위험 범위를 빠르게 수정할 수 있습니다.

또한 각 층의 ESP32 게이트웨이 기준점을 지도 위에 점으로 배치하고, 점들을 연결한 영역을 게이트웨이 존으로 설정할 수 있습니다. 비콘 설치 위치가 현장마다 달라져도 관리자가 기준점을 보정해 RSSI 기반 상대 좌표와 실제 관제뷰를 맞출 수 있습니다.

작업자가 안전고리를 체결하지 않은 상태로 A-Hook 존에 진입하면 조끼와 게이트웨이 단계에서 즉시 경고 상태로 분류하고, 대시보드는 이를 실시간 알림과 지도 표시로 보여줍니다.

### 비상 상황 대응

6축 IMU 센서가 수집한 가속도와 충격 파형을 ESP32 내부에서 분석하여 추락 징후를 저지연으로 판별합니다. 추락 징후가 감지되면 에어백 전개 상태를 대시보드에 반영하고, 화면 전체 비상 팝업과 사이렌 사운드로 현장 관리자에게 즉시 알립니다. 비상 팝업은 관리자가 조끼 사이렌 재전송, 주변 작업자 경고, 확인 및 정지 중 하나의 조치를 선택할 때까지 유지됩니다.

관리자는 해당 작업자의 조끼 사이렌을 다시 작동시키거나, 같은 층 작업자에게 대피 알림을 보내거나, 현장 전체에 방송을 전송할 수 있습니다.

### 게이트웨이 기반 통신

A-Hook은 작업자 조끼가 가까운 게이트웨이에 연결되는 구조입니다. 각 게이트웨이는 주변 조끼의 BLE 데이터를 수집하고, 대시보드는 게이트웨이별 연결 상태, RSSI 품질, 수집 중인 조끼 수를 확인할 수 있습니다.

이 방식은 건설 현장처럼 인터넷과 무선 환경이 불안정한 공간에서도 안정적으로 데이터를 모으기 위한 구조입니다.

### 데이터 분석 및 유지보수

대시보드는 작업자별 위험도를 계산합니다. 안전고리 체결 여부, 추락 신뢰도, 충격 피크값, 배터리, RSSI 상태를 종합해 어떤 작업자를 우선 확인해야 하는지 보여줍니다.

또한 에어백 카트리지 상태와 배터리 잔량을 함께 관리해 사고 대응뿐 아니라 장비 유지보수에도 활용할 수 있습니다. 누적된 안전 로그는 CSV로 내보내 사후 사고 분석, 안전 교육, AI 학습 데이터로 확장할 수 있습니다.

## 하드웨어 및 시스템 구성

### 작업자 조끼

* **Main MCU**: ESP32 기반으로 센서값 수집, 안전고리 체결 판단, 추락 징후 판별, BLE 데이터 전송을 수행합니다.
* **6축 IMU**: MPU6050을 활용해 가속도와 충격 파형을 실시간으로 수집합니다.
* **홀 센서**: 안전고리의 실제 체결 여부를 감지합니다.
* **출력 장치**: 고휘도 RGB LED 스트립과 서보 모터를 활용해 경고 상태와 에어백 전개 상황을 시각적으로 표현합니다.

### 구역별 게이트웨이

* 여러 조끼의 BLE 데이터를 수집합니다.
* 통신 음영 지역을 줄이기 위해 BLE 매쉬 구조를 활용합니다.
* ESPAsyncWebServer 기반 비동기 WebSocket으로 작업자 상태를 대시보드에 스트리밍합니다.
* 웹에서 내려온 사이렌, LED, 대피 알림 명령을 대상 조끼로 중계합니다.

## 핵심 활용 기술

* **엣지 로직**: ESP32 내부에서 서버를 거치지 않고 안전고리 미체결, A-Hook 존 진입, 추락 징후를 즉각 판단합니다.
* **저지연 사고 대응**: 6축 IMU의 가속도와 충격 피크값을 분석해 0.2초 이내 수준의 빠른 경고와 에어백 전개 흐름을 목표로 합니다.
* **RSSI 기반 위치 추정**: 주변 비컨 신호 강도를 스캔하고 가중치 평균 알고리즘을 적용해 작업자의 상대 좌표를 산출합니다.
* **항공뷰 좌표 매핑**: 비컨/RSSI 기반 상대 좌표를 웹 대시보드의 항공뷰 좌표계와 매핑하여 작업자 위치를 직관적으로 표시합니다.
* **게이트웨이 기준점 캘리브레이션**: 절대 좌표를 자동으로 산출하기 어려운 현장 조건을 고려해, 관리자가 실제 설치 위치를 기준점으로 지정하고 이를 작업자 위치 해석에 반영합니다.
* **실시간 양방향 통신**: 게이트웨이와 대시보드 간 WebSocket 연결을 통해 상태 스트리밍과 원격 제어 명령을 처리합니다.

## 제작 및 구현 계획

1. **통신 프로토콜 최적화**
   조끼와 게이트웨이 간 BLE 데이터 포맷, 게이트웨이와 대시보드 간 WebSocket 메시지 구조를 안정화합니다.

2. **펌웨어 고도화**
   FreeRTOS 기반 멀티태스킹을 적용하여 센싱, 위치 추정, 사고 판단, 통신 처리를 독립적으로 수행하도록 개선합니다.

3. **시각적 프로토타입 제작**
   실제 에어백 전개 대신 고휘도 RGB LED와 서보 모터를 활용해 메이커톤 시연에서 사고 대응 흐름을 명확하게 보여줍니다.

4. **관제 웹 최적화**
   층별 작업자의 위치, 상태, 배터리, 에어백, 게이트웨이 연결 상태를 실시간으로 확인할 수 있도록 대시보드 성능과 반응형 화면을 개선합니다.

## 사용자 시나리오

현장 관리자는 태블릿이나 노트북으로 A-Hook 대시보드를 열고 전체 작업자의 위치와 상태를 확인합니다. 만약 작업자가 안전고리를 체결하지 않은 채 위험 구역에 들어가면 해당 작업자는 경고 상태로 표시됩니다.

추락 징후가 발생하면 화면 전체에 비상 알림이 뜨고, 관리자는 즉시 해당 작업자의 위치와 센서 상태를 확인합니다. 이후 조끼 사이렌 재전송, 같은 층 대피 알림, 전체 방송 등 필요한 조치를 대시보드에서 바로 수행할 수 있으며, 사고 대응 흐름은 센서 수집, 엣지 판단, 에어백/LED, 관제 반영 단계로 확인할 수 있습니다.

* 사고 발생 시 위치, 작업자, 센서 상태를 즉시 파악

* 에어백 카트리지와 배터리 상태 관리로 장비 운영 효율 개선
* 축적된 로그 데이터를 기반으로 사후 분석과 안전 교육에 활용
