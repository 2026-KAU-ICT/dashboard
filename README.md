# 세이프티 훅

**세이프티 훅**은 건설 현장의 고소 작업 중 발생할 수 있는 안전고리 미체결과 추락 사고를 예방하기 위한 **스마트 안전 관제 시스템**입니다.

작업자 조끼에 부착된 ESP32 기반 장치가 안전고리 체결 여부와 추락 징후를 현장에서 판단하고, 작업 구역별 게이트웨이가 데이터를 수집해 현장 관리자용 웹 대시보드에 통합 표시합니다.

---

## 문제 정의

건설 현장의 추락 사고는 대부분 짧은 순간의 미체결, 작업자 위치 파악 실패, 사고 감지 지연에서 시작됩니다. 특히 고층 구조물과 철근, 콘크리트가 많은 현장은 통신 환경이 불안정하고, 현장 관리자가 모든 작업자의 안전고리 체결 상태를 실시간으로 확인하기 어렵습니다.

세이프티 훅은 이러한 문제를 해결하기 위해 작업자 단말, 구역별 게이트웨이, 통합 관제 대시보드를 하나의 흐름으로 연결합니다.

---

## 서비스 목표

* 작업자 안전고리 체결 여부를 실시간으로 확인
* 미체결 상태로 위험 구역에 진입한 작업자를 즉시 식별
* 추락 징후 발생 시 0.2초 이내 수준의 빠른 시각 알림 제공
* 현장 관리자에게 전체 작업자 상태, 위치, 배터리, 에어백 상태를 한 화면에서 제공
* 사고 이후 로그 데이터를 축적하여 사후 분석과 안전 교육 자료로 활용

---

## 시스템 동작 흐름

1. 작업자가 세이프티 훅 조끼를 착용합니다.
2. 조끼 내부의 ESP32가 센서값을 읽고 안전고리 체결 여부와 추락 위험 여부를 판단합니다.
3. 조끼는 Bluetooth/BLE로 가까운 작업 구역 게이트웨이에 상태 데이터를 전송합니다.
4. 게이트웨이는 여러 조끼의 데이터를 모아 현장 서버로 전달합니다.
5. 웹 대시보드는 전체 작업자 상태를 항공뷰 지도 위에 실시간으로 표시합니다.
6. 관리자는 웹에서 특정 작업자의 조끼 사이렌, LED, 층별 대피 알림을 게이트웨이를 통해 원격 제어합니다.

중요한 점은 **웹 브라우저가 조끼와 Bluetooth로 직접 연결하지 않는 구조**라는 것입니다. 일반 브라우저는 Bluetooth 지원이 제한적이고 iPhone 환경에서는 제약이 크기 때문에, 세이프티 훅은 게이트웨이가 BLE 데이터를 수집하고 웹은 WebSocket 기반으로 통합 데이터를 확인하는 방식으로 설계했습니다.

---

## 핵심 기능

### 실시간 현장 모니터링

항공뷰 기반 현장 지도 위에 3층, 4층, 옥상 등 작업 구역을 나누어 표시합니다. 작업자의 상대 좌표는 실제 지도 픽셀과 현장 거리 단위로 변환되어 표시되며, 관리자는 층별 필터를 통해 특정 구역만 빠르게 확인할 수 있습니다.

작업자 상태는 정상, 경고, 비상으로 구분됩니다. 정상 작업자는 초록색, 미체결 상태나 위험 구역 진입 작업자는 노란색, 추락 징후가 감지된 작업자는 빨간색으로 강조되어 현장에서 즉시 알아볼 수 있습니다.

### 위험 구역 관리

현장 관리자는 세이프티 훅 존을 지도 위에서 조정할 수 있습니다. 위험 구역의 중심, 반경, RSSI 임계값을 조정하면 게이트웨이를 통해 현장 장치 설정에 반영되는 구조입니다.

이를 통해 현장 구조가 바뀌거나 작업 구역이 변경되어도 관리자가 직접 위험 범위를 빠르게 수정할 수 있습니다.

### 비상 상황 대응

추락 징후가 감지되면 대시보드 전체에 비상 팝업이 표시되고 사이렌 사운드가 재생됩니다. 관리자는 해당 작업자의 조끼 사이렌을 다시 작동시키거나, 같은 층 작업자에게 대피 알림을 보내거나, 현장 전체에 방송을 전송할 수 있습니다.

### 게이트웨이 기반 통신

세이프티 훅은 작업자 조끼가 가까운 게이트웨이에 연결되는 구조입니다. 각 게이트웨이는 주변 조끼의 BLE 데이터를 수집하고, 대시보드는 게이트웨이별 연결 상태와 수집 중인 조끼 수를 확인할 수 있습니다.

이 방식은 건설 현장처럼 인터넷과 무선 환경이 불안정한 공간에서도 안정적으로 데이터를 모으기 위한 구조입니다.

### 데이터 분석 및 유지보수

대시보드는 작업자별 위험도를 계산합니다. 안전고리 체결 여부, 추락 신뢰도, 충격 피크값, 배터리, RSSI 상태를 종합해 어떤 작업자를 우선 확인해야 하는지 보여줍니다.

또한 에어백 카트리지 상태와 배터리 잔량을 함께 관리해 사고 대응뿐 아니라 장비 유지보수에도 활용할 수 있습니다. 누적된 안전 로그는 향후 사고 분석, 안전 교육, AI 학습 데이터로 확장될 수 있습니다.

---

## 사용자 시나리오

현장 관리자는 태블릿이나 노트북으로 세이프티 훅 대시보드를 열고 전체 작업자의 위치와 상태를 확인합니다. 만약 작업자가 안전고리를 체결하지 않은 채 위험 구역에 들어가면 해당 작업자는 경고 상태로 표시됩니다.

추락 징후가 발생하면 화면 전체에 비상 알림이 뜨고, 관리자는 즉시 해당 작업자의 위치와 센서 상태를 확인합니다. 이후 조끼 사이렌 재전송, 같은 층 대피 알림, 전체 방송 등 필요한 조치를 대시보드에서 바로 수행할 수 있습니다.

---

## 기대 효과

* 안전고리 미체결 상태를 관리자가 실시간으로 확인
* 추락 사고 발생 전 위험 패턴을 조기에 발견
* 사고 발생 시 위치, 작업자, 센서 상태를 즉시 파악
* 게이트웨이 기반 구조로 건설 현장의 불안정한 통신 환경에 대응
* 에어백 카트리지와 배터리 상태 관리로 장비 운영 효율 개선
* 축적된 로그 데이터를 기반으로 사후 분석과 안전 교육에 활용

---

## 기술 구성

* **작업자 장치**: ESP32 기반 안전 조끼, 안전고리 체결 센서, IMU 센서, 에어백 상태 관리
* **근거리 통신**: Bluetooth/BLE 기반 조끼-게이트웨이 통신
* **게이트웨이**: 구역별 작업자 상태 수집 및 웹 서버로 데이터 중계
* **관제 화면**: 현장 관리자용 실시간 웹 대시보드
* **데이터 통신**: WebSocket 기반 실시간 상태 동기화 및 원격 제어
