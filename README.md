# A-Hook

**A-Hook**은 건설 현장의 추락 사고를 예방하기 위한 **ESP32 엣지 컴퓨팅 기반 스마트 안전 시스템**입니다. 본 저장소는 현장 관리자를 위한 **실시간 통합 관제 웹 대시보드**의 프론트엔드 소스코드를 포함하고 있습니다.

---

## 핵심 기능 명세

### 1. 실시간 현장 모니터링
* **항공뷰 기반 위치 가시화**: 층별 게이트웨이(3층, 4층, 옥상) 구역을 필터로 구분하고, RSSI 기반 상대 좌표를 실제 맵 픽셀 및 현장 m 단위로 정밀 변환하여 표시합니다.
* **지능형 상태 인디케이터**: 작업자의 상태를 정상(초록), 미체결/위험구역 진입(노랑), 추락 비상(빨간색 깜빡임)으로 직관적으로 시각화합니다.
* **작업자 클러스터링**: 다수 작업자가 밀집된 구역은 숫자로 클러스터링하여 중첩 문제를 해결하고, 개별 리스트 선택 기능을 제공합니다.
* **과거 경로**: 선택된 작업자의 최근 이동 경로를 점선으로 표시하여 사고 전 위험 패턴을 분석합니다.

### 2. 엣지 기반 사고 예방 및 대응
* **Safety Hook Zone 실시간 편집**: 지도 위 위험 구역을 마우스 드래그로 설정하고, RSSI 임계값과 반경을 실시간 수정하여 기기에 즉시 동기화(`UPDATE_ZONE`)합니다.
* **0.2초 초저지연 텔레메트리**: ESP32 엣지 로직의 판정 지연 시간, 6축 IMU 가속도 파형, 추락 판단 신뢰도를 실시간 그래프로 출력하여 0.2초 이내의 빠른 대응을 증명합니다.
* **비상 상황 자동화 플로우**: 추락 감지 시 전면 팝업 및 사이렌 사운드를 즉각 실행하며, 원격으로 조끼 사이렌 재전송 및 주변 작업자 대피 알림을 제어합니다.

### 3. 양방향 원격 제어
* **디바이스 원격 제어**: 특정 작업자의 조끼 LED 모드(꺼짐/점등/점멸)와 부저(사이렌)를 웹에서 직접 원격 제어합니다.
* **통합 알림 센터**: 모든 이벤트(미체결 진입, 추락, 제어 명령 등)를 **[시간 / 위치 / 이름 / 상태]** 형식으로 실시간 로깅합니다.
* **층별/전체 방송**: 특정 층 혹은 현장 전체 작업자에게 실시간 대피 알림을 브로드캐스팅하여 신속한 대피를 유도합니다.

### 4. 데이터 분석 및 관리
* **위험 패턴 분석**: 안전고리 체결 여부, 추락 신뢰도, 충격 피크값 등을 종합하여 작업자별 실시간 위험도를 산출하고 예측합니다.
* **에어백 및 배터리 관리**: 에어백 카트리지 상태(충전됨/사용됨/없음)와 배터리 잔량을 모니터링하여 하드웨어 유지보수 효율을 극대화합니다.
* **CSV 로그 데이터 내보내기**: 누적된 모든 안전 데이터(좌표, 센서값, 이벤트 로그)를 CSV 파일로 추출하여 사후 사고 분석 및 AI 학습 자료로 활용합니다.

## 기술 스택

* **Frontend**: React 19, TypeScript, Vite
* **Styling**: Tailwind CSS
* **Communication**: WebSocket (ESPAsyncWebServer 연동)
* **State Management**: TanStack Query

---

## 시스템 아키텍처

1. **Device Layer**: 작업자 조끼(ESP32)가 센서값 분석 및 추락 판단 후 BLE 전송
2. **Gateway Layer**: 층별 게이트웨이가 데이터를 수합하여 WebSocket 서버로 브로드캐스팅
3. **Application Layer**: React 대시보드가 데이터를 구독하여 실시간 UI 업데이트 및 Downlink 명령 하달
